# Project Reflection – Task Management Dashboard

### 1. What did you learn from this project?

I learned how to build a React application using TypeScript. I practiced creating reusable components, managing state with `useState`, passing props, and handling form submissions. I also learned how to use Tailwind CSS to style my application.

### 2. What challenges did you face?

One challenge was managing tasks when adding, editing, and deleting them. I also had some difficulty implementing search, filtering, and sorting. I solved these challenges by breaking the work into smaller steps and testing each feature.

### 3. How did you use React state management?

I used `useState` to store the tasks, search query, status filter, priority filter, and editing task. When the user adds, edits, or deletes a task, the state updates and React displays the changes.

### 4. Why did you create utility functions?

I created a separate `taskUtils.ts` file to keep reusable functions organized. It contains functions for filtering, sorting, validating task information, and formatting dates. This also helps keep my Dashboard component cleaner.

### 5. What would you improve in the future?

In the future, I would like to add local storage or a database to save tasks, improve the user interface, and add more features to make task management easier.
